# Hearth & Heel

A full-stack winter footwear and hosiery e-commerce platform built with **Java 21**, **Spring Boot**, **PostgreSQL**, and **React**.

## Domain Scope
- **Footwear:** Winter boots, sneakers, heels, and loafers with size-level inventory tracking (`UK 4`–`UK 11`).
- **Winter Essentials:** Thermal wool socks, fleece-lined stockings, and leg warmers.

## Tech Stack
- **Backend:** Java 21, Spring Boot, Spring Data JPA, Spring Security (JWT), Flyway, Validation
- **Database:** PostgreSQL 16 (via Docker Compose)
- **Frontend:** React (Vite), React Router, TanStack Query, Axios
